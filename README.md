## Descripción

El objetivo consiste en facilitar la organización y el seguimiento de medicamentos y permitir registrar medicamentos, configurar horarios, llevar un historial de tomas y recibir recordatorios.
#También contará con fotografías para identificar los medicamentos y un mapa para localizar farmacias cercanas.

## Mockups de la aplicación 

## Pantalla de inicio

Muestra un resumen de los medicamentos registrados, las próximas tomas programadas y los horarios correspondientes.

![Mockup pantalla 1](Mockups/Mockups%201.png)

## Pantalla de medicamentos

Presenta una lista de los medicamentos registrados con su nombre, fotografía, dosis.

![Mockup pantalla 2](Mockups/Mockups%202.png)

## Pantalla de registro de medicamentos

Permite agregar nuevos medicamentos mediante un formulario donde se ingresa el nombre, dosis, presentación, frecuencia, horarios y cantidad disponible.

![Mockup pantalla 3](Mockups/Mockups%203.png)

## Pantalla de filtros personalizados

Permite organizar y buscar medicamentos, facilitando la consulta de información específica.

![Mockup pantalla 4](Mockups/Mockups%204.png)

## Pantalla de farmacias cercanas

Muestra un mapa interactivo donde el usuario podrá visualizar la ubicación de farmacias  y acceder a su ubicación geográfica.

![Mockup pantalla 5](Mockups/Pantalla%204.png)

## Pantalla de detalle del medicamento

Muestra la información completa de un medicamento seleccionado y permite modificar sus datos, eliminarlo o registrar una toma.

![Mockup pantalla 6](Mockups/Pantalla%205.png)

## Pantalla de historial de tomas

Permite consultar un registro de las tomas de medicamentos, mostrando la fecha, hora y estado de cada una, como tomada, pendiente u omitida.

![Mockup pantalla 7](Mockups/Pantalla%206.png)

## Diálogos de confirmación

Muestra mensajes importantes y solicita confirmación antes de realizar acciones como eliminar un medicamento.

![Mockup pantalla 8](Mockups/Pantalla%207.png)
